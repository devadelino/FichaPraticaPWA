1 - O que são operações de “Commit”, “Push” e “Pop” efetuadas num repositório?

  • Commit guarda uma versão das alterações feitas no repositório local
  • Push envia os commits para o repositório no GitHub
  • Pop aplica as alterações de stash no ficheiro

2 – Quais sáo as vantagens de usar Branchs num repositório git?

As branchs permitem experimentar e trabalhar em paralelo separadamente sem afetar todo o repositório. Possiblita também uma melhor organização por funcionalidade.

3 – Nos Merges de conteúdos resultantes de um “Pop” podem resultar em conflitos. Em que consistem e como podem ser resolvidos esses conflitos?

Esses conflitos resultam quando o git não consegue combinar duas versões diferentes de um ficheiro automaticamente e resolve-se analisando os ficheiros em causa e decidindo o que deve ficar e o que deve ser retirado manualmente.

4 – “Clone” e “Fork” são formas diferentes de replicar um repositório Git. Quais as diferenças entre eles?

  1. Clone: copia um repositório remoto para o PC, é local com ligação ao repositório original, sendo necessário permissão para alterar.
  2. Fork: cria uma cópia independente do repositório no GitHub, permitindo alterações livres sem afetar o original.
